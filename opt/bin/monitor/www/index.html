Ротация порта туннеля (обход DPI-заморозки)

Периодически меняет локальный порт AmneziaWG — для ТСПУ это новый поток, что сбрасывает поведенческую «заморозку» (туннель «поднят», но данные молча не идут). Цена — короткий разрыв ~1–2 с при каждой смене. По умолчанию каждые 10 минут.

Управление устройствами

Для каждого устройства в сети выберите режим доступа в интернет.
По спискам — обход блокировок только для сайтов из списков KVASEC (режим по умолчанию).
Напрямую — весь трафик идёт мимо тоннеля, ничего не обходится.
Всё в тоннель — весь трафик устройства идёт через VPN.
Нет интернета — устройство полностью отключается от интернета (штатная блокировка Keenetic, сохраняется после перезагрузки).
🔒 Изоляция — запрет доступа к панелям управления роутера (SSH/Telnet/админка/веб-монитор). Интернет и управление самим устройством не затрагиваются. Защита от «пивота» со взломанного IoT. Доступно для устройств с известным MAC.

Блокировка рекламы

Сетевая блокировка рекламы и трекеров для всех устройств за роутером (через dnsmasq). Работает для рекламы в играх и приложениях, баннеров и аналитики. Видеорекламу YouTube НЕ убирает (общий CDN). Домены из VPN-списка KVASEC автоматически исключаются из блокировки.

«Обновить списки» скачивает актуальные списки рекламы из источников (может занять до минуты). Недоступно, пока активен AdGuard Home.

AdGuard Home

Альтернатива встроенной блокировке: AdGuard Home становится DNS-сервером сети вместо dnsmasq (KVASEC сохраняет текущие DNS-настройки). При первой установке откроется мастер AdGuard Home на порту 3000. Пока AdGuard включён, блокировка рекламы и родительский контроль через dnsmasq недоступны. «Вернуть dnsmasq» останавливает AdGuard и восстанавливает сохранённые настройки.
